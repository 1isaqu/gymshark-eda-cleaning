# Gymshark catalog dashboard

A single-page, scroll-driven data story built on top of this repo's
cleaning pipeline (`gsclean`). It presents the three real EDA findings
from the repo root `README.md` (a flat $1,000 price outlier, a 128-to-7
missing-image cleanup funnel, and a 91-vs-85 category casing
fragmentation) and ends in a gallery of real product photos with a
cursor-tracked 3D tilt effect.

This is a portfolio piece, not a replacement for the separate Power BI
deliverable (`gymshark_analise_prescritiva.pbix`).

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4, via `@tailwindcss/vite` (no PostCSS plugin, no v3
  config file; all theming lives in `src/styles/tokens.css` /
  `global.css` via `@theme`)
- [Motion](https://motion.dev) (`motion/react`) for every animation
- Self-hosted fonts via `@fontsource*` (Instrument Sans Variable,
  Instrument Serif, JetBrains Mono Variable). No Google Fonts `<link>`.
- No chart library: every chart is hand-authored inline SVG.
- No UI component library.

## Data

`src/data/findings.json` is generated by `prepare_dashboard_data.py`
from the cleaned dataset and is committed to the repo (so the site
builds without the raw CSV). It is imported exactly once, in
`src/lib/findings.ts`; every component reads from that module, never
from the JSON file directly. Its shape is documented in
`src/data/findings.d.ts`.

To regenerate it:

```
python prepare_dashboard_data.py
```

## Design system

Colour, type, spacing, motion and shape rules are documented as comments
at the top of `src/styles/tokens.css` and `src/styles/global.css`. Read
those two files before adding a component: they define the one way
tokens are meant to be consumed (Tailwind utilities like `bg-ink` /
`text-accent` first, `var(--token)` only where Tailwind can't reach) and
the documented type scale.

## Development

```
npm install
npm run dev      # start the dev server
npx tsc --noEmit # typecheck
npm run build    # production build to dist/
npm run preview  # preview the production build
```

## Project structure

```
src/
  main.tsx, App.tsx, vite-env.d.ts
  styles/
    tokens.css     # colour tokens (single source of colour truth)
    global.css     # Tailwind entry point, fonts, type scale, base styles
  data/
    findings.json  # generated data (committed)
    findings.d.ts  # its TypeScript shape
  lib/
    findings.ts        # the one place that imports findings.json
    format.ts           # number/currency/percent formatters
    useReducedMotion.ts # prefers-reduced-motion hook
  components/
    SectionShell.tsx  # shared section wrapper (id, rhythm, max-width)
    Figure.tsx         # shared figure + caption primitive
    SiteNav.tsx, SiteFooter.tsx
  sections/
    Overview.tsx, PriceFinding.tsx, ImageFinding.tsx,
    CategoryFinding.tsx, Gallery.tsx, GalleryCard.tsx
```
